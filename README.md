## 📌 About This Repository

Welcome to the **Data Engineering Journey** repository!

This repo documents a structured learning path from **Python and SQL fundamentals** all the way to building **scalable data pipelines, real-time streaming systems, and cloud-based analytics platforms**.

It combines **theoretical foundations** with **hands-on projects** inspired by real-world architectures at companies like **Uber** and **Netflix**.

---

## 🎯 What You'll Learn

### 🐍 Python
Foundations of Python for automation, ETL scripting, and data transformation — variables, OOP, file I/O, error handling.

### ☁️ Cloud & Fundamentals
- **Azure Fundamentals (AZ-900)**
- **Azure Data Fundamentals (DP-900)**
- **Microsoft Fabric & OneLake (DP-700)** — Modern lakehouse architecture

### 🗄️ Databases & SQL
Relational and non-relational databases: **PostgreSQL**, **MySQL**, **Snowflake**, **BigQuery**, **Redshift**, **MongoDB**

### ⚙️ ETL & Data Pipelines
Build and orchestrate data workflows using: **Airflow**, **DBT**, **Spark**, **PySpark**

### 🧩 Big Data & Distributed Systems
Work with large-scale data frameworks: **Hadoop**, **Spark**, **HDFS**, **S3**

### ⚡ Real-Time Data
Stream and process data in motion: **Kafka**, **Spark Streaming**, **Azure Event Hubs**

### ✅ Data Quality & Monitoring
Ensure pipeline reliability: **Great Expectations**, **DataDog**, **Monte Carlo**

### 📊 Analytics & Visualization
Visualize and explore insights: **Power BI**, **DAX**, **KQL (PL-300)**

### 🧠 DevOps & Cloud Tools
Deployment and automation: **Docker**, **GitHub Actions**, **Azure**, **AWS**, **GCP**

### 💼 Real-World Case Studies
End-to-end implementations inspired by **Uber** (ride analytics) and **Netflix** (streaming data) architectures.
